Principais ajustes feitos:

  1. backgroundPosition: 'center 30%' - Isso faz com que o background foque na parte superior da imagem (aproximadamente 30% do topo), onde geralmente estão as pessoas principais em fotos de grupo.

  2. Mantive bg-cover - que faz a imagem cobrir toda a área, mas agora focando na parte mais importante.

Alternativas adicionais caso ainda não fique ideal:

Se ainda estiver com problemas, você pode tentar:

jsx
// Opção 2 - Foco mais específico
style={{
    backgroundImage: 'url(/graduacao.jpeg)',
    backgroundPosition: 'center 25%',
    backgroundSize: 'cover'
}}

// Opção 3 - Para imagens muito verticais
style={{
    backgroundImage: 'url(/graduacao.jpeg)',
    backgroundPosition: 'center top',
    backgroundSize: 'cover'
}}

Recomendação extra: Se possível, considere editar a imagem para um formato mais horizontal (como 16:9) que é mais adequado para backgrounds, ou recortar a parte mais importante da foto para usar como background.
